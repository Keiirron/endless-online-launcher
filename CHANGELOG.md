# Changelog

## 0.1.1

- The launcher now updates itself: it checks GitHub for a newer launcher on start, downloads it in the background and offers to restart.
- Releases now include a `SHA256SUMS.txt` so downloads can be verified.
- Installer file name no longer contains spaces.

## 0.1.0

- First release: install, update and play Endless Online with one button.
- Saved logins, screenshots and chat logs are kept across updates; configs are merged setting by setting and backed up.
- Latest dev post shown in the launcher.
